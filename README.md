# Arthur Social Club — Artists Roster

One-sheet estático para Biera, Michelle Espinosa, Derian Diorian y Edgar Flin.

## Publicar en Vercel
1. Descomprime `asc-one-sheet-v3.zip`.
2. Sube la carpeta `asc-one-sheet-v3` a un repositorio de GitHub.
3. En Vercel, selecciona **Add New → Project** y conecta ese repositorio.
4. No necesitas configurar framework ni comando de build: es una web estática.
5. Pulsa **Deploy**.

También puedes desplegar la carpeta con Vercel CLI usando `vercel` desde su interior.

## Archivos
- `index.html`: contenido y enlaces del roster.
- `styles.css`: diseño responsive.
- `images/`: fotografías de los cuatro artistas.

Los enlaces de EPK, Spotify y fotografías ya están integrados. El contacto de Emily abre WhatsApp.
